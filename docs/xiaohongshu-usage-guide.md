# Omni2MP3 小红书使用说明

## 笔记标题

音乐格式太多不好整理？用 Omni2MP3 批量转成 MP3

## 正文

手里有从音乐软件下载的 NCM、QMC、KGM 等音乐文件，想整理成通用的 MP3？可以试试 Omni2MP3。它在浏览器里处理你选中的本地文件，转好后可以一次打包下载。

🎧 **怎么用**

1. 打开网页：<https://magiicccc.github.io/music-batch-unlock/>
2. 点「选择音乐文件」，在文件选择窗口里选中一个或多个已下载的音乐文件；也可以把文件直接拖进页面。想继续处理其他文件，可以再选一批加入队列。
3. 看「本批进度」和每个文件的状态，等进度条完全变绿。失败的文件会单独提示；可以先确认文件完整、格式受支持，再重试。
4. 在下方检查转换结果。需要的话可以试听、编辑歌曲名/歌手/专辑/封面，或删除不需要的结果。
5. 选择文件名格式，然后点「下载 ZIP」，把成功转换的歌曲一次下载到设备。

📁 **目前支持什么**

- 常见加密音乐：网易云 NCM/UC、QQ 音乐 QMC/MFLAC/MGG、酷狗 KGM/KGMA/VPR、酷我 KWM，以及虾米 XM、喜马拉雅 X2M/X3M、咪咕 MG3D 等常见格式。
- 普通音频：MP3、FLAC、OGG、M4A、WAV，以及 AAC、WMA、AIFF、APE、Opus 等格式。
- 输出统一为 MP3。原本就是 MP3 的文件会直接保留；其他格式会在本机转码。个别受保护、损坏或特殊编码的文件可能无法处理。

✨ **几个小提示**

- 建议少量多次转换，文件太多或太大时会占用较多设备内存。
- 网页里的转换结果暂存在当前页面中；下载 ZIP 后再关闭页面，避免忘记保存。
- 转换失败时，先确认文件来自设备本地且下载完整，再用最新版 Chrome 或 Edge 重试；首次转码需要加载编码组件，请保持网络连接。
- 音频处理在浏览器本地进行，音频内容不会上传。若当前部署启用了匿名使用统计，页面可能发送功能使用、文件格式/大小区间和处理结果等信息；不会发送音频内容、文件名或歌曲标签。统计是否启用取决于网站部署配置。
- 请只处理你有权使用的音乐文件，并遵守相关平台条款和版权规定。

它适合把自己已下载的音乐快速整理成 MP3，尤其是需要批量转换、统一命名的时候。收藏起来，下次找文件不用一个个手动处理～
